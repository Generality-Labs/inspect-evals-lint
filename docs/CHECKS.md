# Rule index

The rule index is on the documentation site: <https://inspect-evals-lint.generality.org/CHECKS/>. It lists every rule by category and explains suppression. Each rule's page is also in [rules/](rules/), and `inspect-evals-lint --explain <code>` prints it locally.

The index is built with the site, not committed, because every new rule changes it. This file stays because releases up to 0.10.0 link here. The site build replaces it with the generated index.
