### Changed

- The package builds with `uv_build` instead of hatchling, and its version is set once in `pyproject.toml`; `inspect_evals_lint.__version__` reads it from the installed metadata. The wheel holds the same files and metadata as before, apart from `__init__.py`'s version lookup. The sdist now holds only the package source, `README.md`, `LICENSE` and `pyproject.toml`, not the whole repository.
