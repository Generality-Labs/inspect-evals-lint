### Added

- `readme_task_args` (IEFS007) checks the `-T name=value` arguments in the README's `inspect eval` and `inspect eval-set` commands, in fenced code blocks and inline code, with or without `uv run` and across line continuations. Each task the command names is resolved against the package's `@task` functions as `<namespace>/<task>`, a bare `<task>` or `path/to/file.py@task`, and every `-T` name must be a parameter of every resolved task. Inspect drops an argument the task does not take and only logs a warning, so the command runs with the default. Tasks that do not resolve to the package, such as placeholders and other packages' tasks, and tasks that take `**kwargs` are not checked. A README generator that rewrites a generated parameter list does not read the hand-written examples around it, which is how these drift. Findings are errors ([#59](https://github.com/Generality-Labs/inspect-evals-lint/issues/59)).
