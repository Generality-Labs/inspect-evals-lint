### Added

- `readme_dependency_groups` (IEFS008) checks the extras and dependency groups the README's commands install. In a `uv` command, `--extra X` must name an extra under `[project.optional-dependencies]` and `--group X` a group under `[dependency-groups]`. In a `pip install` (also `pip3`, `python -m pip` and `uv pip`) or `uv add` command, `project[X]` must name an extra when the project is the repository's own or `.`. Names are compared in normalised form. The governing `pyproject.toml` is the repository's, or the evaluation's own `<isolated-packages-dir>/<name>/pyproject.toml` when it has one, and the message names it. Other projects' extras, placeholders, `uv` commands with `--project`, `--directory` or `--package`, and commands after a `cd` in the same code block are not checked. A `pyproject.toml` that is not valid TOML skips the rule. A name that exists as the other kind gets a hint to switch flags. Findings are errors ([#60](https://github.com/Generality-Labs/inspect-evals-lint/issues/60)).
