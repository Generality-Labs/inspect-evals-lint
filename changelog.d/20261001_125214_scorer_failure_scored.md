### Added

- `scorer_failure_scored` (IEBP012) reports a scorer that turns a grader or sandbox failure into a score. It flags a broad handler (`except:`, `except Exception`, `except BaseException`, alone or in a tuple) that does not `raise` among its own statements, whose `try` awaits a grader call (`.generate(`, or an outside call named `judge` or `grader` or ending in `_judge` or `_grader`) or a sandbox `.exec(`/`.read_file(`. The handler must return a result fixed in the source (`0.0`, `False`, `None`, `""`, a NaN, a module-level or imported upper-case name such as `INCORRECT`, a tuple starting with one, a dict holding one, `Score.unscored(...)`, or `Score(value=<any of these>)`); assign a constant to a name returned later; rebind a name the `try` sets, index into a name or append to one, with a constant or a dict holding one, where the name is read after the `try`; or fall through, leaving a name the `try` would have set at the constant it held before the `try`, where the name is read after it. A `raise` inside an `if` does not exempt the handler. A handler that then leaves by `continue`, `break` or a return of anything else is not reported, and neither is a falsy value the code tests with `is None` or `not` and then raises, continues or returns a non-constant on. Only code a scorer runs is read: `@scorer` functions, the functions nested in them, and the package functions they call at any depth, across the package's modules. `@tool` functions, solvers and probes are not read, and a package helper that swallows its own failures is not reported again at its callers. A narrowed handler such as `except FileNotFoundError` is not reported. It is an error around a grader call and a warning around a sandbox call, since a missing file can be the agent's fault. The hint recommends letting the error propagate, and `Score.unscored(reason="grader_failed")` only when the grader replied without a usable verdict. For a sandbox timeout it says the error can be either, so let it propagate unless the time limit is part of the task, and then read the exit code of a `timeout` run inside the sandbox. A suppression comment on any line of a multi-line `except (...)` header covers the finding. Method calls on instances or parameters are not followed yet ([#56](https://github.com/Generality-Labs/inspect-evals-lint/issues/56)).
