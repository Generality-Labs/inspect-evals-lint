### Added

- `custom_metric_tests` (IETS008) warns about each custom `@metric` that no test runs through the real epoch reducer. A test counts when it imports the epoch helper module, `metric_epochs` by default (`tests/utils/metric_epochs.py` in inspect_evals and the evaluation template), and names the metric as a whole word, or the name given in `@metric(name=...)`. A hand-written test that runs `eval()` with `epochs=` is not counted. A unit test that hands a metric hand-built scores misses the reducer, which turns `"C"` into `1.0` even at `epochs=1` and two passes in three epochs into 0.667. The helper module can be renamed with `[tool.inspect-evals-lint.custom_metric_tests] helper-module`, which takes a bare or dotted module name. It is a warning, and a presence check only.
