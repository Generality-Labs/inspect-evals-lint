### Added

- `grader_model_under_test` (IEBP013) reports a scorer whose grader silently resolves to the model under evaluation. It flags `get_model()` with no model, no `role=` and no `default=`, and `get_model(state.model)` or `get_model(str(state.model))`, when the result is used for `.generate(...)`: on the call itself, or on a name it is assigned to, alone or as an alternative such as `grader = grader_model or get_model(...)`. A name counts until it is next bound, and in nested functions only when they do not bind it themselves, so a tokenizer lookup followed by a rebinding, or a nested `score()` with its own `model`, is not reported. Only code a scorer runs is read, found as for IEBP012. A call that only reads the result, such as `get_model().name` for a tokenizer, is not reported, and `get_model(model)` with a parameter that defaults to `None` is left for a later rule that reads the guards. Calls with `role=` stay with IEBP002. It is an error ([#61](https://github.com/Generality-Labs/inspect-evals-lint/issues/61)).
